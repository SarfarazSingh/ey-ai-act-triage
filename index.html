What the client must do with evidence

    When it bites

    Application dates as amended by the AI Omnibus. Milestones that apply to the system on screen are highlighted.

    Where this fits in EY's AI assurance work

    Evidence first

    Each obligation names the artefact that proves it. The triage output doubles as the request list for an AI Act readiness review.

    Built for the edge cases

    Art. 6(3) exemptions and fine-tuned GPAI models are where clients misclassify. The tool puts the reasoning on the page, where a reviewer can challenge it.

    Built by someone who has been inspected

    I ran nuclear safety compliance on a submarine, where every control had to be evidenced. AI assurance asks the same question of a different system.
